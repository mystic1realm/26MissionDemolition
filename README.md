# 26MissionDemolition
To progess through the levels, you have to press the N key.


This project is a Unity physics-based game inspired by Mission Demolition. The player launches a projectile with a slingshot to knock down the castle ahead.

Enhancements:
1. Four Custom Levels
There are four seperate levels with the castle layout becoming bigger than the first castle layout from Level 1.

2. Level Progression
Players can press N to advance to the next level. After Level 4, pressing N displays the game over screen.

3. Game Over Screen and Restart
Players can press G to display the game over screen. The screen includes a Play Again button that restarts the game back to Level 1.

4. Projectile Launch Sound
A sound effect plays when a projectile is launhed, providing audio feedback during gameplay.

- There are titles for the levels to indicate what level you're on.

Controls:
- Launch: Click and hold the projectile and drag the mouse to aim in the direction you want the projectile to go.
- N: Advance to the next level.
- G: Display the Game Over screen.
- Play Again: Press to restart at Level 1.

How to Play:
Launch projectiles at the castle and experiment with the physics to knock the blocks down Progress through the four levels using the N key.

Technologies:
- Unity
- C#
- Unity physics and collision system
- Audio playback
